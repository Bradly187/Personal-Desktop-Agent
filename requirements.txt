# PATH as the phonemizer backend, plus the model weights (kokoro-v1.0.onnx +
# voices.bin) downloaded into tts/ via tts/download_kokoro.py. KokoroClient
# degrades gracefully (raises an actionable RuntimeError) when missing.

#
# GPU (RTX 5090) — OPT-IN, install separately, do NOT uncomment here.
# onnxruntime-gpu installs into the SAME `onnxruntime` import namespace as the
# CPU build that chromadb / faster-whisper / magika pull in transitively, so it
# can't be a plain pinned line — it must REPLACE the CPU package:
#     pip uninstall -y onnxruntime
#     pip install onnxruntime-gpu==1.24.3
# Requires the CUDA 12.x runtime + cuDNN 9 DLLs on PATH (the matching wheel for
# the installed onnxruntime version). kokoro_tts._select_onnx_provider() then
# auto-selects CUDAExecutionProvider; it falls back to CPU if the GPU stack
# fails to load, so this is safe to skip. Override with ONNX_PROVIDER=...
