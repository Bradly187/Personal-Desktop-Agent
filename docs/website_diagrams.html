Diagram 2
Input Modalities
↕️
Tilt Navigation
iPad tilt drives cursor position or velocity. One-Euro adaptive filter smooths tremor. Pain-day mode relaxes thresholds automatically.
Stack: Core Motion · One€ filter · Gyro bias calibration
🎙️
Voice Commands
Wake phrase "hey agent" arms a 15-second window. Whisper large-v3 on GPU transcribes. Acoustic profiler adapts VAD per user voice condition.
Stack: faster-whisper · Silero VAD · Acoustic profiler
✌️
Hand Gestures
Peace-sign base pose detects 13 spatial gestures: swipes, grabs, snaps, monitor moves, push/pull, pinch. LiDAR validates grab depth.
Stack: MediaPipe Tasks · LiDAR depth · velocity calibration
👆
Touch / Trackpad
Full multi-touch trackpad pad on iPad screen. Direct touch commands bypass the LLM entirely for zero-latency control.
Stack: SwiftUI TrackpadView · WebSocket bypass

All 16 verbs flow through CommandExecutor. DomainClassifier gates the pipeline — simple commands go to llama3.1:8b (verb-first); dev-domain queries go to DevAgent which selects a specialist model. MOUSEDOWN/MOUSEUP execute synchronously (no asyncio.to_thread) for timing-critical drag operations.
Diagram 5
4-Gate Routing Pipeline
G0
Gate 0 — Privacy Screen
Blocks commands containing sensitive patterns (passwords, API keys). No LLM call made — command is rejected before any model sees it.
→ REJECT or pass
G1
Gate 1 — Domain Classification
Keyword scoring classifies intent into COMMAND, CODE, MATH, VISION, PLAN, or GENERAL. Routes to the appropriate inference path.
→ domain label
G2
Gate 2 — Local Inference
Command domain: llama3.1:8b (verb-first, 190ms warm). Dev domains: specialist model via ModelRouter (qwen3-coder, deepseek-r1, etc.). 15s circuit-breaker → CLARIFY.
→ Command or fallthrough
G3
Gate 3 — Cloud Fallback
When local inference times out or scores low confidence. Command domain → claude-haiku-4-5. Dev domain → claude-opus-4-8. 10s timeout circuit-breaker.
→ Command or CLARIFY
G4
Gate 4 — Execution & Verification
CommandExecutor maps verb → MCP tool call. ActionVerifier does perceptual diff (pre/post screenshot) for CLICK, OPEN, CLOSE, SCROLL. UIAutomation finds targets by fuzzy name.
→ ack + status reply to iPad
