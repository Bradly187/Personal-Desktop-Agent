System Components

Each layer operates independently and degrades gracefully. No single sensor is required — the system adapts to whatever inputs are available.

🖥️

MCP Server

Standalone Model Context Protocol server exposing 14 desktop control tools via stdio transport. Claude calls these tools directly to act on the Windows desktop.

pyautogui win32gui mss pix2tex EasyOCR
📱

iPad Bridge

WebSocket server on port 8765 receiving 13 message types from the iPad app. Dispatches sensor data to FusionEngine, trackpad events directly to pyautogui, and handwriting to OCR.

aiohttp WebSocket mDNS asyncio
🧠

Fusion Engine

10-level priority sensor fusion running at 60 Hz. Higher-priority inputs (touch, sound) short-circuit lower ones (voice). Tilt and head tracking bypass the LLM entirely.

asyncio 60Hz tick priority queue
🔀

Hybrid Coordinator

4-gate routing engine deciding local vs cloud inference. Gate 0 (privacy) forces local for sensitive commands. Gates 1-4 check confidence, complexity, VRAM, and latency.

Ollama AWS Bedrock pynvml EMA tracking
🤖

Local Inference

Abstract base class with swappable backends. OllamaInference (dev, ~450ms), VLLMInference (production target, ~280ms), and NemotronInference (4B model for constrained VRAM).

Ollama vLLM Nemotron-mini RTX 5090
👁️

iPad Sensors

Native Swift app capturing TrueDepth gaze, ARKit head pose, Core Motion tilt, Speech Framework keywords, and AVFoundation sound actions — all streamed over WebSocket.

ARKit Core Motion Speech AVFoundation
✍️

Handwriting OCR

Apple Pencil strokes captured on iPad, sent as PNG to PC. pix2tex converts handwritten math to LaTeX, then to Unicode for pasting into any application.

pix2tex pylatexenc PencilKit
🌐

Web Client

Safari fallback when native app isn't available. Full trackpad, command grid, scientific keypad, and Scribble handwriting input — served directly by the bridge server.

Vanilla JS WebSocket PWA-ready
📈

Continuous Trainer

Background learning system that adapts routing thresholds, gesture confidence floors, and Whisper vocabulary based on usage patterns. No manual reconfiguration needed.

aiosqlite few-shot memory threshold tuning

Design Principles

🌿 Graceful Degradation

Every modality is optional. The system functions with any subset of sensors active. No hard dependencies on any single input.

⚡ Local-First

All inference runs on the RTX 5090. AWS services are fallback only, triggered when local confidence is low or GPU is saturated.

🔄 Adaptive

Routing thresholds, gesture floors, and Whisper vocabulary self-tune over time. No manual reconfiguration required.

♿ RA-Aware UX

Oversized touch targets, dwell activation, palm rejection, relaxed thresholds on bad pain days. Lower-effort interactions always preferred.
